# 项目入口与日常流程

## 项目入口

- **主程序**：`backend/app/main.py` (FastAPI 应用)
- **前端入口**：`frontend/src/main.js` (Vue 应用)
- **配置文件**：
  - `backend/.env` (后端环境变量)
  - `frontend/.env` (前端环境变量)
  - `docker-compose.yml` (容器编排)

## 日常开发流程

1. **领取任务**
   - 在 `changes/` 下创建以日期命名的文件夹（如 `2026-06-27-task-name`）
   - 使用 `templates/task-template.md` 模板记录任务

2. **记录变更**
   - 在对应任务文件夹中填写任务目标和验收标准
   - 每次代码修改都记录变更说明

3. **开发与修改**
   - 遵循项目代码风格
   - 复用已有模块，避免重复造轮子
   - 确保安全性，不引入新风险

4. **验证**
   - 运行预设的验证方式（测试、构建等）
   - 确保所有变更通过验证

5. **完成任务**
   - 在任务文件夹内填写实际验证结果
   - 附带一行简要变更说明
   - 同步更新相关文档
