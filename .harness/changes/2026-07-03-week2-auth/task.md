# 任务

## 任务名称

第2周：管理员认证

## 任务描述

实现管理员登录认证系统，使管理员可以登录本监测平台。

详见 [规划文档](../../../.planning/2-PLAN.md)

## 拆解步骤

1. 创建 JWT 依赖注入（`app/core/deps.py`）
2. 创建认证路由（`app/api/auth.py`）
3. 注册路由到 main.py
4. 创建 Seed 脚本（`backend/scripts/seed.py`）
5. 更新 Token 过期时间为 24 小时
6. 前端 Login.vue 对接真实 API
7. 前端路由守卫

## 预期结果

- 管理员可登录并获取 JWT token
- 已登录管理员可创建新管理员
- 种子脚本可初始化默认管理员
- 前端登录页可正常登录
- 未登录自动跳转登录页
