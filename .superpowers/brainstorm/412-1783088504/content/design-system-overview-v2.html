5️⃣ 整体氛围总结

  • 白 + 浅灰 为主，深蓝 #1a1a2e 作为导航/侧栏 → 稳重不轻浮
  • 蓝色 #2563eb 作为主交互色，点缀在按钮/链接/激活态
  • 卡片 白色背景 + 极细边框 #e5e7eb，阴影仅用于 hover 状态
  • 字体使用 Inter + Noto Sans SC，确保英文数字清晰、中文优雅
  • 整体 留白充足，靠字重（weight）和间距划分层级，而非边框
