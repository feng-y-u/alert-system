## 32.5 术语表

| 术语 | 含义 | 备注 |
|---|---|---|
| 被监控系统 | 上报登录日志的校园业务系统（如统一身份认证） | 本平台的数据来源；`monitored-app` 是其仿真实现 |
| 管理端 / 平台用户 | 使用本平台监控与处置告警的人 | 与「被监控用户」严格区分 |
| 频率异常 `frequency` | 5 分钟内同一用户名登录 ≥ 10 次 | 阈值硬编码 |
| 设备异常 `device` | 1 小时内同一用户名出现 ≥ 3 个不同 `(user_agent, ip_address)` 组合 | 阈值硬编码 |
| 告警去重 | 24 小时内同用户同类型存在 `pending` 告警时不再新建 | 见 `services/detection.py:152` |
| 实时检测 | 日志上报后立即由 Celery 单条触发的检测（传 `log_id`） | 窗口终点取该日志 `login_time` |
| 定时检测 | Celery Beat 每小时执行的增量检测 | 窗口终点取当前 UTC 时间 |
| 检测游标 | Redis 键 `anomaly_detection:last_check_time` | 用于定时检测的增量起点 |
| SSE | Server-Sent Events，单向服务器推送 | 本项目替代 WebSocket 的方案 |
| ID 前缀 | `/api`（**不是** `/api/v1`） | 变量名为 `API_V1_PREFIX` |
| 主机端口 | MySQL 8881 / Redis 8880 / 后端 8000（Docker）或 8001（本地）/ 前端 8882（Docker）或 5173（dev） | 开发中最易混淆的一组数字 |
