## 文档约定（重要）

本文档对结论的可信度做了显式分级，请在引用时一并保留：

| 标记 | 含义 |
|---|---|
| **源码事实** | 可直接在标注的 `文件:行` 读到 |
| **实测** | 本次审计在本机运行命令得到的输出（命令见 `99-附录.md` §32.2） |
| **分析结论** | 由代码结构推导，未在真实运行环境复现（例如涉及 MySQL 外键级联、连接池耗尽的结论） |
| **未确认 / 源码中未发现 / 推测** | 无法从源码证实，列于 `99-附录.md` §32.4，**不得当作事实引用** |
| 📄 | 来自前端/Flutter 子代理报告且已抽样复核的条目 |

- 所有敏感值一律以 `<YOUR_API_KEY>`、`<YOUR_PASSWORD>`、`<YOUR_SECRET>`、`<YOUR_SMTP_PASSWORD>` 占位，正文不出现真实凭据。
- 所有 Mermaid 图均依据源码生成，图中每个节点都能在源码中定位；未在源码出现的模块不画。

## 维护约定

1. 改动代码后，请同步更新对应章节的 `文件:行` 引用；行号会随重构漂移，**行号用于定位而非长期锚点**。
2. 新增端点必须同时更新 `05-API文档.md` 与 `06-数据库设计.md`（若涉及新模型）；新模型必须登记到 `backend/app/models/__init__.py`（否则 Alembic autogenerate 漏表）。
3. 发现文档与源码冲突时，**以源码为准**，并修正文档；本套文档已知的上一版漂移点已在各章标注。
