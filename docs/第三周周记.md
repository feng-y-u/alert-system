## 遇到的问题与解决

### 1. 端口冲突
**问题：** 8080 端口被 Steam 占用  
**解决：** 检查 `netstat` 发现 PID 6352 是 steamwebhelper，杀掉后重启后端

### 2. CORS 跨域错误
**问题：** 浏览器提示 "CORS Missing Allow Origin"  
**原因：** 后端实际未启动，请求被其他进程拦截  
**解决：** 确认后端正常启动后再测试

### 3. 表格列宽分配
**问题：** 用户代理列太窄，状态列与前面间距过大  
**解决：** 将状态列移到用户代理列之前，使用 `min-width` 自适应

### 4. 文本换行问题
**问题：** ID 405 显示成两行，表头文字折行  
**解决：** 添加 `white-space: nowrap` 和 `word-break: keep-all`
