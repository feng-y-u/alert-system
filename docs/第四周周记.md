### 2. 检测规则

**频率异常检测：**
- 规则：同一用户5分钟内登录超过10次
- 严重级别：10-30次 → medium，>30次 → high
- 窗口计算：滑动窗口，以当前日志时间往前推5分钟

**设备异常检测：**
- 规则：同一用户1小时内User-Agent或IP地址发生变化
- 严重级别：2个设备 → medium，≥3个设备 → high

### 3. 架构实现

**实时检测：**
```
POST /api/logs → create_log() → detect_anomaly_for_log.delay(log_id) → Celery异步
```

**定时检测：**
```
Celery Beat 每小时运行 → 仅检测上次检测后产生的新日志 → 增量检测
```

**告警去重：**
```python
24小时内是否存在pending的同类告警 → 存在则跳过
```

## 技术要点

### 滑动窗口频率检测
```python
def detect_frequency_anomaly(db, username, log_id=None):
    if log_id:
        log = db.query(LoginLog).filter(LoginLog.id == log_id).first()
        end_time = log.login_time
    else:
        end_time = datetime.utcnow()

    start_time = end_time - timedelta(minutes=5)

    count = db.query(func.count(LoginLog.id)).filter(
        LoginLog.username == username,
        LoginLog.login_time >= start_time,
        LoginLog.login_time <= end_time
    ).scalar()
```

### 设备检测 SQL 优化
```python
# 使用 SQL DISTINCT 代替 Python set 去重
rows = db.query(LoginLog.user_agent, LoginLog.ip_address).filter(
    LoginLog.username == username,
    LoginLog.login_time >= start_time,
    LoginLog.login_time <= end_time
).distinct().all()

device_count = len(rows)
```

### 增量检测 + 去重
```python
# 定时检测：先更新检测时间，避免异常导致重复处理
set_last_check_time(current_time)

# 只查上次检测后的新日志
users = db.query(LoginLog.username).filter(
    LoginLog.created_at >= last_check_time
).distinct().all()

# 告警去重：24小时内同类pending告警不重复创建
def should_create_alert(db, username, alert_type):
    existing = db.query(Alert).filter(
        Alert.username == username,
        Alert.alert_type == alert_type,
        Alert.status == "pending",
        Alert.created_at >= datetime.utcnow() - timedelta(hours=24)
    ).first()
    return existing is None
```

## 遇到的问题与解决

### 1. 数据库迁移 PYTHONPATH
**问题：** `alembic revision --autogenerate` 找不到 `app` 模块
**解决：** 手动创建迁移文件，不依赖 `--autogenerate`

### 2. `since` 参数未使用
**问题：** 设计文档中包含 `since` 参数，但实现时未使用
**解决：** 移除未使用的参数，保持代码简洁

### 3. 设备检测性能
**问题：** 使用 `all()` 加载所有行再用 Python 遍历去重，大数据量时性能差
**解决：** 改用 `db.query().distinct().all()` 只返回两列，SQL 层去重

### 4. 定时检测重复处理
**问题：** `last_check_time` 在检测完成后更新，异常时导致重复处理
**解决：** 将 `set_last_check_time` 移到开始处，先更新再检测
